Copilot 配置指南

VSCode

安装插件: GitHub Copilot
修改 VSCode 的 settings.json 文件, 添加以下配置:
{
    "github-enterprise.uri": "https://my.ghe.com",
    "github.copilot.advanced": {
        "authProvider": "github-enterprise"
    }
}

Visual Studio 2026

更新 VS 2026 最新版
开启 GitHub Enterprise 账户支持： - **工具** → **环境** → **账户** → 勾选 **包含 GitHub Enterprise 服务器账户**
输入 https://my.ghe.com
完成设备码登录

Copilot CLI

安装Copilot CLI
命令行输入 copilot 启动
输入 /login
选择2 GitHub Enterprise Cloud (*.ghe.com)
输入 https://my.ghe.com
Sign in with your browser (recommended) 与 Sign in with a device code 随便选一个
完成登录
